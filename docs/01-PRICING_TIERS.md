# PRICING TIERS - Complete Feature Breakdown

## Overview

Maksy uses a single codebase with feature flags. All users see the same UI, but features are locked/unlocked based on subscription tier. This keeps upgrades seamless while avoiding code forks.

Maksy offers **three plans:**

- **Pro** ($47/month) - For service businesses
- **Scale** ($97/month) - For growing service businesses
- **Maksy Team** ($29/month + $8/seat) - For non-service businesses

## AI Request Limits

Maksy AI uses **daily** request counters. Each request increments the counter immediately. When the limit is reached, the chat UI displays a warning and disables message input until the next reset.

| Plan       | Limit Type     | Allowance       | Model        | Behavior When Limit Reached                                                           |
| ---------- | -------------- | --------------- | ------------ | ------------------------------------------------------------------------------------- |
| Pro        | Daily per user | 30 requests/day | Standard GPT | Banner: "You've used all Maksy AI requests for today". Input disabled until midnight. |
| Scale      | Daily per user | 50 requests/day | Advanced GPT | Banner with upgrade tips + link to advanced insights; input disabled until midnight.  |
| Maksy Team | Daily per user | 30 requests/day | Standard GPT | Banner: "You've used all Maksy AI requests for today". Input disabled until midnight. |

**Reset logic:**

- All counters reset automatically at 00:00 company-local time.
- Admins can reset an individual user's counter from Settings → Ask Maksy (logged in audit trail).

## Upgrade/Downgrade Logic

### Upgrading

- **Pro → Scale:** unlocks advanced GPT model, automation builder, unlimited team, financial AI dashboard, dynamic pricing engine, and automation templates instantly. Billing is prorated automatically.
- **Team → Pro:** unlocks all service business features (jobs, services, estimates, invoices, GPS). Team member count converts from seat-based to flat rate (up to 5). Billing switches from $29 + seats to $47 flat.
- **Team → Scale:** unlocks all service business features plus advanced Scale features. Team member count stays unlimited. Billing switches from $29 + seats to $97 flat.
- **Trial flow:** all plans offer a 14-day trial without a card. Before the trial ends, users must add a payment method.

### Downgrading

- **Scale → Pro:** archives automation builder workflows (kept read-only), disables financial AI dashboard and dynamic pricing, downgrades AI model to standard; team count resets to 5 (extra members deactivated until reassigned).
- **Pro → Team:** removes all service business features (jobs, services, estimates, invoices, GPS, inventory, booking page). Customer data and tasks remain. Team member count converts to seat-based billing. Billing switches from $47 flat to $29 + $8/seat.
- Downgrades are handled through support to ensure data export/archiving is completed and users understand feature loss.

### Trial Countdown

- Displayed at the top of the app during trials
- Shows days remaining and a CTA to "Add payment method" or "Upgrade now"

## Feature Gating Implementation

### Frontend Example

```typescript
// Example: Feature gate for service business features
import { getFeatureAccess } from '@/lib/feature-gates';

if (!getFeatureAccess(user.plan, 'jobs')) {
  return <LockedFeature feature="Jobs" requiredPlan="pro" />
}

// Example: Check AI limit
if (usage.aiRequestsRemaining === 0) {
  return <DailyLimitBanner plan={user.plan} />
}
```

### Database Schema

```sql
-- subscriptions table
plan_type         text    NOT NULL CHECK (plan_type IN ('pro', 'scale', 'team'))
seat_count        integer DEFAULT 1  -- For Team plan
stripe_seat_price_id text            -- Stripe price ID for $8/seat addon
trial_ends_at     timestamptz
features_enabled  jsonb   -- optional overrides

-- ai_usage_counters table (per user per day)
company_id        uuid    NOT NULL
user_id           uuid    NOT NULL
usage_date        date    NOT NULL
requests_used     integer NOT NULL DEFAULT 0
UNIQUE (company_id, user_id, usage_date)
```

### Middleware Enforcement

```typescript
// Example middleware protecting a service business route
import { isServiceBusinessPlan } from '@/lib/feature-gates'

const { plan } = await loadSubscription(companyId)

if (!isServiceBusinessPlan(plan)) {
  return error(403, 'This feature requires a Pro or Scale plan')
}

// Example AI limit check
const { plan, requestsUsedToday, dailyLimit } = await loadUsageContext(user)

if (dailyLimit !== null && requestsUsedToday >= dailyLimit) {
  return error(429, 'Daily Maksy AI limit reached')
}
```
